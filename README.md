웹·앱·펌웨어·소프트웨어·클라우드를 대상으로 취약점을 연구하는 **보안 연구자이자 버그헌터**입니다.
현대적인 보안 엔지니어링과 아키텍처 설계·리뷰를 수행하고, 다양한 보안 도구를 활용하거나 직접 제작합니다.

최근에는 **AI SAST/DAST와 취약점 자동 진단·검증**을 연구하며, AI 시대에 맞는 보안 업무 방식을 탐구하고 있습니다.

### Current research

- **AI SAST / DAST** — AI 기반 정적·동적 분석, 취약점 자동 진단 및 검증, 보안 분석 워크플로 연구
- **Bug hunting** — Apple, 다양한 플랫폼, 오픈소스를 대상으로 취약점 분석 및 버그헌팅 진행
- **Web / Mobile / Firmware** — 웹·모바일 해킹, 웹·앱·펌웨어 분석, 소프트웨어 분석 및 리버싱
- **Security engineering & architecture** — 보안 아키텍처 설계·리뷰, 현대적인 보안 엔지니어링, 클라우드 보안
- **Security tooling** — 각종 보안 도구 활용, 분석 환경 구성, 연구와 업무에 필요한 도구 설계·제작

### Building an AI Security Engineer

**진행 중인 프로젝트** · 취약점 탐지·분석·검증을 지원하는 AI Security Engineer를 만들고 있습니다.

AI SAST/DAST와 자동 진단·검증 연구를 바탕으로, AI가 실제 보안 엔지니어링 업무를 수행하는 방식을 탐구합니다.
