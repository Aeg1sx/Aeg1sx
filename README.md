**David Han / Aegis**

Security researcher working across **web, applications, tools, and hardware**.

My work spans vulnerability discovery, root-cause analysis, and validation of security impact. I investigate failures across component and system boundaries, from application logic and software tooling to the interactions between software and hardware.

### Research scope

| Domain | Focus |
| :--- | :--- |
| **Web & applications** | Web services, APIs, and application security; behavior across components and trust boundaries. |
| **Tools & software** | Security tools, developer tooling, and the assumptions built into software workflows. |
| **Cloud & infrastructure** | Cloud platforms, service integrations, and infrastructure security. |
| **Hardware & systems** | Hardware security and the interactions between physical components and software. |

### Selected public work

- **[Aegify](https://github.com/Aeg1sx/Aegify)** — Source security analysis with traceable evidence, optional AI investigation, and a self-hosted team workspace.

- **[IDOR Scout](https://github.com/Aeg1sx/idors-scout)** — API authorization testing with two-account validation and browser-context checks.
